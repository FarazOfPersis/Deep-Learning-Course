## 📚 Core Topics Covered

### 1. Foundations & Optimization

* **Neural Networks from Scratch:** Implementing forward passes, backpropagation, and manual weight updates to understand core mechanics.
* **Optimization Landscape:** Analyzing how different optimizers, including SGD, Adam, and RMSprop, adjust weights and learning rates.
* **Training Techniques:** Understanding loss functions, gradient-based optimization, regularization, and practical neural network training.

### 2. Computer Vision & Sequence Modeling

* **Image Segmentation:** Leveraging dense prediction architectures to process, segment, and read visual sequences, including Captcha/OCR tasks.
* **Temporal Data:** Managing hidden states and sequential dependencies using Recurrent Neural Networks (RNNs) and LSTMs.
* **Generative Vision Models:** Studying and implementing VAEs, VQ-VAEs, and diffusion-based image generation.
* **Vision-Language Learning:** Exploring CLIP and multimodal representation learning through image-text alignment.

### 3. Self-Supervised Learning & Representation Learning

* **Self-Supervised Learning (SSL):** Learning useful representations from unlabeled data by designing pretext or proxy learning objectives instead of relying on manually labeled datasets.
* **Contrastive Learning:** Understanding how contrastive objectives learn representations by bringing related samples closer while separating unrelated samples.
* **SimCLR:** Implementing a contrastive self-supervised learning framework using data augmentation, positive/negative pairs, projection heads, and contrastive loss.
* **Representation Learning:** Studying how neural networks can learn transferable feature representations that can later be used for downstream tasks.
* **Multimodal Contrastive Learning:** Exploring image-text representation alignment through approaches such as CLIP.

### 4. Advanced LLMs & Generative AI

* **Parameter-Efficient Fine-Tuning (PEFT):** Adapting large foundational language models efficiently under strict hardware and VRAM limitations.
* **Inference Optimization:** Studying inference techniques and deployment strategies to make model inference faster and more memory-efficient.
* **Retrieval-Augmented Generation (RAG):** Connecting large language models to vector search systems and databases to ground responses in external data.
* **Modern Generative AI:** Working with large language models and generative architectures, including diffusion and other neural generative models.
