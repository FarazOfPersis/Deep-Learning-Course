## 📚 Core Topics Covered

### 1. Foundations & Optimization
* **Neural Networks from Scratch:** Implementing forward passes, backpropagation, and manual weight updates to understand core mechanics.
* **Optimization Landscape:** Analyzing how different optimizers (like SGD, Adam, and RMSprop) adjust weights and manage learning rates.

### 2. Computer Vision & Sequence Modeling
* **Image Segmentation:** Leveraging dense prediction architectures to process, segment, and read visual sequences (e.g., Captcha/OCR tasks).
* **Temporal Data:** Managing hidden states and sequential dependencies using Recurrent Neural Networks (RNNs) and LSTMs.

### 3. Advanced LLMs & Generative AI
* **Parameter-Efficient Fine-Tuning (PEFT):** Adapting massive foundational language models efficiently under strict hardware and VRAM limits.
* **Inference Optimization:** Implementing strategies and deployment techniques to make model inference faster and more memory-efficient.
* **Retrieval-Augmented Generation (RAG):** Connecting large language models to vector search systems and databases to ground responses in real data.
